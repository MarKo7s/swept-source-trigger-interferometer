# Changelog

All notable changes to trigger are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-07-17

### Added

- Pip-installable package layout (`pyproject.toml`, git-tag release via `scripts/release.py`).
- Package export of `PSOC5_trigger` / `feedbackmode` from `psoc5.py` (formerly `trigger.py`).
- Optional `notebooks` extra (matplotlib, jupyter, ipykernel) for `trigger_example.ipynb`.
